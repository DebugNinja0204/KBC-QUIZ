# 🧠 Kaun Banega Crorepati (KBC) Quiz Game 🎯  

A console-based quiz game inspired by the popular Indian TV show **Kaun Banega Crorepati** (KBC), built in **C language**.  
It includes lifelines like **50/50**, **Audience Poll**, and **Skip Question**, along with a timer, colourful UI, and prize progression!

---

## 📜 Features

✅ **Interactive Gameplay** – Answer multiple-choice questions within a time limit.  
✅ **Three Lifelines** –  
   - 🎯 *50/50*: Removes two incorrect options.  
   - 👥 *Audience Poll*: Displays simulated audience votes.  
   - ⏩ *Skip*: Skips the current question.  
✅ **Timer-Based Questions** – Encourages quick thinking!  
✅ **Colored Output** – Uses ANSI color codes for better visual appeal.  
✅ **Dynamic Prize Money** – Win increasing rewards for each correct answer.  
✅ **Cross-Platform** – Works on both Windows and Linux (with small changes).  

---

## 🧩 How It Works

- Each question has:
  - The **question text**
  - **Four options (A, B, C, D)**
  - The **correct option**
  - A **timeout value**
  - The **prize amount**
- The player must select an answer within the given time.
- Enter `L` to use a lifeline (if available).
- Game ends when:
  - The answer is wrong ❌  
  - Time runs out ⏰
